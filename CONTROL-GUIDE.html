Clip → documented routes only

PLAY, CUE, Grid Start, hot cues, pitch and phase are translated to Syndicate’s Clip routes. Hot cues are taps, not held previews. Clip/Loop means restart at end, not a track loop; slip/jump/formant/speed remain blocked.

Slip loops → one owner per deck

Tap D or T to select timing; tap the active one again for straight. Hold pad A; hold B to hear B’s repeat. Release B while holding A to return to A; release final length to stop repeating without clearing timing.

Timing starts straight per deck. D/T changes during a hold retrigger the active repeat. Mouse edits are not tracked; graceful exit clears D/T. Resuming a loop does not promise to preserve its old region.

No hidden jump range. Shift + a mode button selects a bank; holding Shift + a pad is a different gesture. Each deck remembers its bank.
Watch the console. It shows LEFT / RIGHT deck, player type, bank and selected repeat timing. Unsupported type-specific controls are blocked, not guessed.

Syndicate 0.1.901 removed per-step OSC controls.
Both former step banks have eight unassigned pads and eight unassigned Shift+pads. They cannot edit steps.

Use Syndicate itself for step editing; the bridge does not invent another OSC route. No pad step-state LEDs, velocity editing, lane mute or direct sample hits are assigned.

Setup: use Syndicate four-deck view; disable direct FLX4 MIDI. Enable OSC input 9090, feedback to 127.0.0.1:9096 and Toggle All (including TempoSliderEnabled). Feedback is change-only, with no rate setting. Default profile/wire root: /Syndicate/; custom roots must match in Syndicate and settings.json. See README.md and root rules.

Boundaries: controls may need to be visible in Syndicate. No jog/scratch, crossfader, held cue preview or arrangement-internal mixing. Shift+HOT CUE pad loops work on tracks only; they are cue regions, not fixed beat lengths. Use 4BEAT/EXIT to leave one. Stop/restart after an app restart or uncertain state; Ctrl+C attempts releases, but UDP loss/force-kills cannot guarantee delivery.

Startup target is unknown until paired left/right hardware selector reports arrive; no guessed initial target. Left/right deck selection via Shift+LOAD also retargets FX. In 1&2 both selected main mixer channels receive the same value, including explicit on/off.

LEVEL/DEPTH → Macro 1 wet

14-bit knob position sends normalized Mixer/CHn/FX/Macro/1. Without documented macro feedback, this is not feedback pickup: the first complete knob report after activation or retarget only establishes a baseline.

  1. Physically turn to exact 0/dry to send 0 and arm. If already dry, nudge away then back.
  2. Subsequent movement sends 0–1 wet to the selected channel(s).

Another known bridge writer of that route (including LC3) re-arms dry-home. Mouse/external plugin edits have no writer identity and cannot be tracked without feedback.

FX ON/OFF → Macro 2 enable

FX ON/OFF: explicit Mixer/CHn/FX/Macro/2 = 1 on. Either Shift + FX ON/OFF: explicit 0 off. Not a toggle; it does not alter Macro 1 wet or the entire insert chain.

The FX LED is not driven: it does not show effect state. No macro feedback subscription or startup/shutdown macro writes. OSC sends do not confirm the plugin acted. FX SELECT pushbutton, BEAT arrows and Macros 3–8 remain unassigned.

Operation boundary: Only the FLX4 EFFECT controls above map to these macros; PAD FX remains the slip-loop bank (page 1). External plugin settings are yours to configure. Hardware and Syndicate end-to-end behaviour remain unverified.
